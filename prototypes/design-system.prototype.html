Trilha — design system port

A throwaway harness for issue #7. The prototype's styles.css encodes two dimensions in one channel — hue is discipline, intensity is status — and it works because --hue is reassigned on :root at runtime and every rule downstream reads it. The question is whether that survives being split into tokens.css + base.css + CSS modules, with the swap moved from a JS style write onto a data-discipline attribute — and whether the Map, which writes stroke, fill and stroke-opacity as SVG presentation attributes, can express the same encoding in CSS instead.
